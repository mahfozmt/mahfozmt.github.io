# Palette's Journal

## 2026-11-07 - Skip Link and Programmatic Focus Targets in Single-Page Portfolios
**Learning:** In sticky-header single-page portfolio layouts with interactive sticky navigations, keyboard users face repetitive tab burdens before accessing primary content. Simply linking `#main-content` is insufficient for assistive technology if the destination landmark lacks programmatic focusability; assigning `tabindex="-1"` to `<main>` allows smooth programmatic focus without inserting it into natural tab order. Additionally, matching `:focus-visible` ring colors directly to the editorial `--border-focus` token maintains brand harmony while satisfying WCAG 2.4.7.
**Action:** When creating skip links on pages with sticky navigation bars, ensure `<main id="main-content" tabindex="-1">` is styled to suppress intrusive mouse focus outlines (`main:focus { outline: none; }`) while keyboard `:focus-visible` remains crisp and visible.

## 2026-11-08 - Keyboard Dismissal and Focus Return for Overlay Navigation Drawers
**Learning:** Responsive drawer navigations that overlay viewport content often leave keyboard and screen-reader users trapped or disoriented if dismissing requires tabbing all the way through drawer items back to the toggle button. By listening for `Escape` (`document:keydown.escape`) when the drawer is open, keyboard users can instantly dismiss the overlay. Crucially, explicitly restoring programmatic `.focus()` to the triggering toggle button (`#mobileMenuBtn`) prevents focus from resetting to `<body>`, while updating `aria-label` between "Open mobile menu" and "Close mobile menu" ensures screen reader users receive explicit auditory context of the disclosure action.
**Action:** Whenever implementing a collapsible overlay navigation or drawer menu, couple state management with an Escape key listener that restores focus to the invoking trigger and dynamically toggles the trigger's `aria-label`.
